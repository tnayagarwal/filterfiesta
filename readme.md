Face Landmarks Detection & Snapchat Filter
📌 Overview

This project demonstrates real-time facial landmarks detection and the application of Snapchat-style filters using Mediapipe and OpenCV.

Key features include:

Detecting faces using BlazeFace (via Mediapipe)

Extracting 468 facial landmarks in real-time

Overlaying virtual filters (glasses, masks, accessories)

Running efficiently on CPU (200+ FPS on flagship devices)

🛠 Features

Face Detection using Mediapipe’s BlazeFace

Landmark Detection for eyes, lips, nose, and face outline

Custom Filters like sunglasses or fun masks

Real-Time Processing with OpenCV

📂 Project Structure

notebook.ipynb → Main Jupyter Notebook with code and explanations

assets/ → Images for Snapchat-style filters (optional)

output/ → Saved results or screenshots
